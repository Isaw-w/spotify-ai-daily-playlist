Spotify AI Daily Playlist Source

AI daily playlists for Spotify

A small Spicetify extension. You describe your taste in a text file, then Codex or Claude Code creates a new playlist for the day.

git clone https://github.com/Isaw-w/spotify-ai-daily-playlist.git
cd spotify-ai-daily-playlist
npm run install-extension

Use

  1. Edit data/profile.md.
  2. Run npm start.
  3. Ask Codex or Claude Code to create today's playlist.

Local only. No Spotify OAuth app. No analytics. MIT licensed.

The extension changes one configured playlist. It does not change Liked Songs or other playlists.
